Fractal Boundary Explorer

The hat-tiling grid is built by growing one huge recursively-substituted "supertile" to a given level, then cropping it with a plain axis-aligned box. Supertiles have self-similar, non-convex (notched) outlines — so whenever the crop edge lands in a notch instead of the solid interior, you get a jagged, fractal-looking "missing tile" region. This tool exposes that mechanism directly so you can find and play with it.
